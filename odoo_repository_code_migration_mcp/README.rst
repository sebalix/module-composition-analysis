Expose the Odoo modules code element migration data collected by the
Odoo MCA modules through an MCP (Model Context Protocol) server.

This module adds the code element migration tools to the MCP server
declared by ``odoo_repository_mcp``:

- follow an element across the Odoo versions: its next version
  counterpart, its full history and any draft proposal
- list the declared code renames/removals with pagination and filters
- list the elements absent from the next version, with their resolution
  status, resolution counters and data classification (demo, noupdate or
  overriding records); only data records loaded by the module are listed
- propose new renames/removals as timelines (draft by default, or
  directly confirmed for high-confidence proposals), applied to the
  analysis once confirmed

.. IMPORTANT::
   This is an alpha version, the data model and design can change at any time without warning.
   Only for development or testing purpose, do not use in production.
   `More details on development status <https://odoo-community.org/page/development-status>`_

Usage
=====

Timeline proposals
------------------

The write tools (``code_create_timeline``, ``code_update_timeline``,
``code_delete_timeline``) create, update and delete timelines, but only
**draft** ones can be updated or deleted: a manual review and confirms
them in the UI before they impact the migration analysis.

``code_create_timeline`` and ``code_update_timeline`` also accept a
``confirm`` input to create or confirm a timeline directly: reserve it
to high-confidence proposals, as a confirmed timeline immediately
impacts the migration analysis.

To allow a client to propose timelines, add its user to the
``Code Timeline Editor`` group
(``odoo_repository_code_migration_mcp.group_code_timeline_editor``).
Read-only clients only need the ``Odoo MCA User`` group (see
``odoo_repository_mcp``).
