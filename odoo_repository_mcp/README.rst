Expose the Odoo MCA data through an MCP (Model Context Protocol) server,
for AI agents.

This base module declares the MCP server and its authentication, and
provides tools to query the collected data:

- search modules, get their details (manifest, dependencies, versions
  history) and explore their dependency graph
- list the known Odoo versions and repositories

.. IMPORTANT::
   This is an alpha version, the data model and design can change at any time without warning.
   Only for development or testing purpose, do not use in production.
   `More details on development status <https://odoo-community.org/page/development-status>`_

Usage
=====

Installation
------------

Install this module together with the Odoo MCA modules collecting the
data (``odoo_repository`` at least). The MCP submodules add their own
tools to the same server when installed.

Expose the server to AI clients
-------------------------------

- Enable the developer mode, then go to ``AI > MCP Server``
- Open the ``Odoo MCA MCP`` server
- Click ``Add Key`` to generate an API key for a client: the key is
  displayed only once
- Configure the AI client with the ``URL`` shown on the server form and
  the generated key as ``Bearer`` token

Security
--------

- Tools run with the permissions of the user set on the API key: this
  user must belong to the ``Odoo MCA User`` group
  (``odoo_repository.group_odoo_repository_user``) to read the collected
  data
- Create one key per client; keys can be expired individually from the
  server form
- Every call is logged and can be audited in ``AI > MCP Server Log``
